This NILTASK server intentionally skips Web Push for users who already have a native FCM token, to prevent duplicate notifications. For a clean PWA test, use a NILTASK account that is not registered in the native APK.

Closed-app test

  1. Get every important diagnostic above to PASS.
  2. Close this page and close the installed PWA.
  3. From another NILTASK account/device, send a DM or group message to this test user.
  4. If the Android system notification arrives while the PWA is closed, Web Push is proven.
  5. Repeat once with the phone screen locked.

This deliberately uses NILTASK's real push_subscriptions → send-push → service worker route, so it tests the production architecture rather than a fake local notification.
